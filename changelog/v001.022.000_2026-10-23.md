# 2026-10-23

## Sort result columns without a mouse

Keyboard users can now choose ascending or descending sort for the active result column from the command palette, alongside the existing keyboard-accessible filtering and column navigation.

Answers [Azure Data Studio #26425](https://github.com/microsoft/azuredatastudio/issues/26425) (result-column sorting and filtering were inaccessible from the keyboard).

## Wide decimals show every digit

Result grids now show `decimal` and `numeric` values exactly when they are too wide for a floating-point number: integers past 19 digits (a `numeric(38,0)` key, say) and decimals with more than 15 significant digits used to be painted with their last digits rounded off. They also sort exactly, and Match Row, quick filters, and Top Values use the digits the database sent. Pivot sums and charts still use the nearest floating-point value, and Excel stores them as numbers, which Excel holds to 15 digits.

## Competitor issue check

Checked result-grid behavior against ten competitor reports. [DataGrip DBE-6439](https://youtrack.jetbrains.com/issue/DBE-6439) (stacked query results) — already available through the stacked results layout. [Azure Data Studio #26193](https://github.com/microsoft/azuredatastudio/issues/26193) (results panel grows while switching tabs) — checked, the results height changes only during an explicit divider drag. [HeidiSQL #2303](https://github.com/HeidiSQL/HeidiSQL/issues/2303) (long column lists are hard to navigate) — the searchable Go to Column popover already provides keyboard navigation. [HeidiSQL #2478](https://github.com/HeidiSQL/HeidiSQL/issues/2478) (first clipboard copy fails) — checked, the editor writes the selected text directly to the system clipboard on every copy. [Beekeeper Studio #4631](https://github.com/beekeeper-studio/beekeeper-studio/issues/4631) (choose a foreign-key target row) — foreign-key autocomplete already fills the referenced key, including for empty values. [Sequel Ace #2688](https://github.com/Sequel-Ace/Sequel-Ace/issues/2688) (Pinyin IME loses composition during inline editing) — checked, SQLly edits rows in a form using standard text inputs rather than transient inline cell editors. [Redis Insight #4858](https://github.com/redis/RedisInsight/issues/4858) (large integers lose precision) — checked, full signed 64-bit integers render exactly, with a regression test added.
