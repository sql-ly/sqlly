# 2026-08-12

## SQLLY for Windows on ARM

There is now a Windows **arm64** download, alongside the existing x64 one. It runs natively on Windows 11 on Snapdragon and other ARM laptops — no x64 emulation, so it starts faster and drains less battery than running the x64 build under translation. The on-prem bridge connector ships for Windows arm64 too.

Every Windows download is now checked against its own architecture before it is published, so an arm64 download can never turn out to contain an x64 program.
