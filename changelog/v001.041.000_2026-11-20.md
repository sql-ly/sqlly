# 2026-11-20

## Markdown cells edit as Markdown and help you use notebook values
Editing a Markdown cell no longer offers SQL keywords, tables, SQL hover cards, SQL warnings, formatting or AI SQL suggestions. Instead the text is coloured as Markdown, the / menu and Ctrl+Space offer Markdown snippets (headings, lists, tables, code blocks, quotes, callouts, dividers, bold, italic, links and pictures), Enter continues a list and ends it on an empty item, Tab and Shift+Tab nest list items, and brackets, backticks and emphasis marks close themselves. Typing {{ lists the formula values and parameters the text can show with their current values (sensitive parameters stay hidden), a picture's destination lists the notebook's picture attachments, hovering over a reference shows its value and whether it is stale or partial, and a reference to a name the notebook doesn't have is underlined. SQL cells keep their IntelliSense and {{…}} references as before.
