# 2026-09-04

## Native-tool discovery tests fixed on Windows

Two `tool_discovery` tests registered fake `pg_dump`/`mysqldump` binaries by their bare names, but the resolver probes for the platform executable name (`pg_dump.exe` on Windows), so the tests failed on Windows. They now build the on-disk names through the same suffix helper the resolver uses, so the coverage runs identically on every platform.
