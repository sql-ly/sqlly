# 2026-09-18

## Fix the browser build after the sidebar redesign

The sidebar redesign left the browser (WebAssembly) build broken. The new header icon buttons and the "no connections" empty state draw their icons through `gpui_component`'s `Icon`, but that import was still marked desktop-only, so the browser build could not find it. The import now applies to every platform. Desktop is unaffected — it already had the import — and the browser app builds again.
