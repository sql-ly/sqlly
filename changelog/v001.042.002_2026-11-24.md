# 2026-11-24

## Plan operator properties keep the engine's order everywhere

The engine-reported properties in a plan operator's details (Limit and Offset, a hash join's strictness and algorithm, a ClickHouse read's parts, granules and index conditions) now always appear in the order the engine wrote them. The desktop app already showed them that way. The online query plan viewer, built separately, could list them alphabetically instead.

## French number separators show in the browser build

The plan pane formats numbers in French with a narrow no-break space between digit groups (1 760 lignes). The browser build's fonts had no glyph for that character, so the separator could render as a missing-glyph box. The fonts now include it.
