# 2026-10-20

## Redis time-series labels in a stable order

Redis time-series labels (`TS.MRANGE … WITHLABELS`) are now always written with their keys in sorted order; before, the order depended on how the app happened to be built. The `sqlly://connection/new` deep link now stores its parsed connection on the heap, as the other link kinds do.

## In-app updates check SHA-256 checksums

Each release download now has a published SHA-256 checksum. The in-app installer hashes the update as it downloads and throws it away if the result doesn't match; a release without a recorded checksum is never installed in-app, only offered as a browser download.
