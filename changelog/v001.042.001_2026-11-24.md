# 2026-11-24

## URL parsing library updated for a security advisory

The `url` library SQLly uses to parse connection and link addresses is updated from 2.5.8 to 2.5.9, which fixes RUSTSEC-2026-0592: a URL nested in many `blob:` prefixes could overflow the stack and crash the process when its origin was read. Version 1.42.0 never shipped because the release's dependency audit caught this advisory, so 1.42.1 is the first release with the rebuilt plan pane.
