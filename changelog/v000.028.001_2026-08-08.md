# 2026-08-08

## Relay connections work from any paired machine

Connecting through a relay no longer appears to require the SQLLY Bridge on the same machine as the app. The connection editor now offers "Authorize" on each device that has not paired with a bridge yet (instead of silently borrowing another device's pairing), relay profiles resolve their authorization from the signed-in device itself so they work on any machine, and the bridge accepts a secure handshake from any authorized device rather than only the first one that ever paired.

## Version 0.28.1

The application version moved from 0.28.0 to 0.28.1.
