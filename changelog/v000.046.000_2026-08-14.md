# 2026-08-14

## Accented text in SQL no longer crashes the app

Typing or opening SQL that contains accented or other non-ASCII characters — for example a Spanish name in a comment — could crash the app while it scanned the text for completions, located the WHERE clause, split MySQL scripts, or parsed a typed color. All of those scans now step through text one full character at a time instead of one byte at a time, and regression tests cover the reported crash.
