# 2026-10-21

## In-app update install no longer fails as "incomplete", and can be cancelled

Every in-app update download failed with "The download was incomplete". The download was fine, but the size check read the expected length after the whole file had arrived, when the HTTP client reports the bytes still to come (zero) instead of the file's size. The size is now read before downloading starts.

While an update downloads or is being checked, the Update Summary dialog now shows only Cancel next to the progress. Cancel stops the download, removes anything already unpacked, ends any wait to install when idle, and brings back the usual buttons. The Mac App Store edition is unchanged: it never checks for or downloads updates itself, because the App Store installs them.
