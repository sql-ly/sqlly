# Changelog - 2026-07-17 (v0.10.0)

## Result grid improvements

Upgraded the data table component to v3.1.2, which fixes scrolling behavior with pivot view fields and adds support for row operations without hierarchy. The result grid now handles complex pivoted data layouts more smoothly and provides greater flexibility for configuring row display and interaction patterns.

### Under the hood

- The data table component bumped from 3.0.2 to 3.1.2.
