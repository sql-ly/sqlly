# 2026-09-29

## DuckDB never opens a file twice while it is closing

When the last tab or tool using a DuckDB file closed and another opened it again straight away, SQLLY could briefly hold two database instances on the same file. That could corrupt an index ("Failed to delete all rows from index") or, on Windows, fail with "the file is being used by another process". Reopening now waits until SQLLY's own previous instance has finished closing.
