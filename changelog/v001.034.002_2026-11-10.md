# 2026-11-10

## Typing in the query editor is instant again
Since 1.31.0, on a connected tab each typed character reached the screen 80–120 ms late, even in an empty editor. The scrolling work in that release stopped redrawing the editor on every window frame, and typing was relying on those frames. The editor now redraws itself on every edit.

## An idle window stops redrawing
The tab bar and status bar each kept a refresh timer that restarted the other's, so a window nobody was touching redrew about twelve times a second. They now share one timer that stops as soon as both are up to date.

## Other things that showed late after 1.31.0
The same scrolling work left a few more things waiting for an unrelated redraw. Closing a dialog or switching split panes now gives the editor keyboard focus straight away, instead of leaving typing dead until a click. The editor and explorer scrollbars resize as soon as the content or the pane changes size, and the explorer no longer leaves blank rows after a large height change. The sidebar, AI and results toggles in the title bar follow their keyboard shortcuts immediately. Azure servers discovered while the explorer was empty appear without moving the pointer.
