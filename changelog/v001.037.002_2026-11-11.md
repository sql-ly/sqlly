# 2026-11-11

## Reliable macOS release builds

A test that resumes a saved AI conversation failed intermittently when it ran alongside the other AI panel tests, which stopped the v1.37.1 macOS release build. Tests now keep saved conversations in temporary storage of their own and no longer write into the real profile of the machine running them.

## Groundwork for large results in the browser preview

The format SQLLY uses to keep large results on disk can now be stored somewhere other than a local file. This is the first step toward letting the browser preview keep very large results in browser storage instead of memory. Nothing changes visibly yet.
