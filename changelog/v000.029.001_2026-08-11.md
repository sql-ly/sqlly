# 2026-08-11

## The bridge now runs on any Linux machine, desktop or server

`sqlly-bridge register` failed on headless Linux hosts with a `Platform secure storage failure: DBus error`, because a server without a desktop session has no OS keyring available.

The bridge now uses the OS keyring (macOS Keychain, Windows Credential Manager, or the Secret Service on Linux) whenever it is reachable, and falls back to owner-only files when no keyring is available, so registration works on headless servers too. `register` and `status` now print a `secret storage:` line stating which backend is in use (and, when falling back, why the keyring was unavailable).
