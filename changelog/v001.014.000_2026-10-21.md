# 2026-10-21

## JetBrains Mono is the new editor font

The SQL editor now uses JetBrains Mono by default. It has a clearly heavier bold for keywords, true italics for comments, and a tall x-height that reads well at small sizes. The font ships inside the app (Regular, Medium, SemiBold, Bold, Italic, and Bold Italic), so it looks the same on every machine without installing anything. Fira Code is still bundled and can be picked again in Settings → Appearance.

Updating to this version switches the editor font to JetBrains Mono once, whatever font was picked before. A font picked after the update is kept.
