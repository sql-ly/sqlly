## Release build fixes

A feedback-queue test could fail when it ran at the same moment as the rate-limit test, because both share the queue's pause state; it now waits its turn. This stopped the macOS release of 1.29.2, so 1.29.3 is the first 1.29 release to ship and includes everything listed for 1.29.0 through 1.29.2.
