# 2026-11-02

## Release build fixes

The browser preview builds again: a sign-in error helper that only the desktop app uses no longer gets compiled into the browser version. The bundled zlib build dependency (libz-sys) moves to 1.1.31, which stops its build script from writing the build environment into the build folder (RUSTSEC-2026-0418). Version 1.29.0 never shipped because of these two problems; 1.29.1 includes everything listed for it.
