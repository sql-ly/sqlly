# 2026-11-18

## SQLly for Intel Macs

macOS now has a second download: a signed, notarized DMG for Intel Macs alongside the Apple Silicon one, both needing macOS 13 or later. It is the same app, built from the same release, so in-app updates on an Intel Mac fetch the Intel build. The release pipeline cross-compiles it on the Apple Silicon build Mac, and each DMG holds exactly one architecture (no universal binary). The Mac App Store edition, SQLly Bridge, sqlly-cli and SQLly Embedded stay Apple Silicon only for now.

Asked for by [MaFtX](https://github.com/MaFtX), who reported [Sequel Ace #2325](https://github.com/Sequel-Ace/Sequel-Ace/issues/2325) (Sequel Ace slow and laggy since 5.1.0) and wanted to try SQLly on an Intel Mac.

## Bundled zlib updated for a heap buffer overflow

The zlib that SQLly compiles in, used for MySQL protocol compression and PNG decoding, is updated to libz-sys 1.1.33, which fixes a heap buffer overflow in zlib ([RUSTSEC-2026-0544](https://rustsec.org/advisories/RUSTSEC-2026-0544)).
