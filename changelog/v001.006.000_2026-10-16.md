# 2026-10-16

## Linux and Windows arm64 releases ship the app only

The Linux and Windows arm64 downloads now contain the desktop app only; the on-prem bridge and the command-line engine stay available for amd64 (and the bridge for macOS). The arm64 desktop app is unchanged.

## Windows downloads include duckdb.dll

Windows builds now use DuckDB's official prebuilt library instead of compiling DuckDB from source, so the Windows download (and the command-line engine) now include a `duckdb.dll` next to the executable — keep the two together. DuckDB works exactly as before, including reading Parquet and JSON files.
