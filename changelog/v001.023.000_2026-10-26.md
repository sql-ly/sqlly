# 2026-10-26

## Language changes refresh every open window

Changing the language now refreshes cached controls in every open window and keeps the browser build's chrome aligned with the application.

## IntelliSense Improvement: accepting a suggestion no longer reopens the popup

Accepting a table alias or column suggestion now leaves the completion popup closed instead of immediately reopening it at the same position. Automatic suggestions resume when you type again, and you can still reopen the popup manually. This fixes ifb_4629 (regression test `accepted_alias_does_not_reopen_completions_ifb_4629`) and ifb_0c92 (regression test `accepted_column_does_not_reopen_completions_ifb_0c92`).

## Open About and open-source licenses in the browser

Help → About SQLLY and Open Source Licenses now open inside the browser workbench, with the version, credits, and license details available without a separate window. Help uses the same labels on desktop and in the browser, and the panels can be closed to return to the query.
