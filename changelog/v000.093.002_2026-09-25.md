# 2026-09-25

## Browser build fixed after the clause-aware IntelliSense change

The v0.93.1 browser (wasm) build failed. The new GROUP BY / clause-aware completions call the model engine's cursor-context and fuzzy-matching helpers, which were compiled only into the desktop app. The browser build now includes those text-only helpers; value completion, which needs a live connection pool, stays desktop-only.
