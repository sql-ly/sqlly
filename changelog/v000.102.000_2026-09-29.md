# 2026-09-29

## Results font and size setting

Preferences → Display now has a Results Font section next to the interface and code fonts. You can choose the font family and size for the results grid, pivot tables, and charts, and open grids update immediately. A custom size scales row heights to match; until you change it, the size still follows the Results row density setting. The Code Font description no longer claims it controls result cells, since it never did.
