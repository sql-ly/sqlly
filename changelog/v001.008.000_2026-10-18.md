# 2026-10-18

## SQLly in the browser can open straight into a query

A launch link for SQLly in the browser can now carry query tabs to open: one or more scripts, the connection and database each runs on, a tab title, values for the script's parameters and where to put the cursor. SQLly opens those tabs connected, with the values in the parameter strip, and runs nothing until the user presses Run. The tabs open only for the first session of a launch, so a page reload restores the workbench instead of opening them again.

## PostgreSQL and other non-SQL Server connections connect cleanly through a bridge

Connecting to a PostgreSQL (or MySQL, SQLite, DuckDB, ClickHouse or Oracle) server through SQLly Embedded or a Via-Relay connection showed "Could not connect … relation sys.databases does not exist" and left the database list empty, because the database list was always fetched with SQL Server's query. It now uses each engine's own catalog, so the connection succeeds and its databases appear in the explorer.

## Inactive tabs name the server they are pinned to

The small server name shown on an inactive query tab now names the connection that tab runs against, instead of repeating the server of the tab you are looking at.
