# 2026-09-10

## Fix disabled database right-click actions

Right-clicking a database in the explorer left every menu item between Copy Name and Refresh — New Query, Browse Objects, Run SQL File, Search, the exports, Import, and Drop Database — greyed out whenever that database's server was not the single globally active connection (including right after launch, before you had clicked the server). A right-click now assumes the server and database the item lives on: the items enable whenever that server has a saved profile, and choosing one retargets to it — connecting if nothing was active for that server, or switching database if only the database differed — before it runs. New Query in particular used to open against whatever connection happened to be active; it now opens against the database you clicked.
