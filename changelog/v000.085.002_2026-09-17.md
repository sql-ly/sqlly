# 2026-09-17

## Pivot save works for rows-only (and columns-only) layouts

The pivot sidebar's save button silently did nothing for the everyday "group by several columns" layout: the `-- sqlly pivot:` directive round-trip required both a Rows and a Columns field. A pivot with a single populated axis now saves and re-loads correctly — the directive simply omits the empty axis.

## Pivot save no longer depends on grid-creation order

The pivot and chart save handlers captured the query editor when the grid was first built; a grid created before the editor attached made the save button a permanent silent no-op. Both handlers now resolve the editor at save time.

## Pivot and Chart tabs lock on spill-backed results

Results large enough to spill to disk run the grid in windowed mode, where the interactive pivot silently aggregated only the resident rows and its double-click drill-through could not filter the grid at all. Both tabs now lock with a "Result too large" status on spill-backed result sets, matching how they lock while a query streams.
