# 2026-11-11

## Autocomplete for every formatting directive

Typing a `-- sqlly` comment now brings up suggestions at every step. A bare `--` offers a ready-made starter line for each kind of directive, `-- sqlly ` lists every directive, and inside one the list shows the settings it takes that are not on the line yet, then the values each setting allows — chart kinds, pivot aggregates, grid filter operators, map modes, number and date formats, time zones, colors and the rest. Wherever a directive expects a column, the columns from the tab's last run are offered and written with the quoting that directive needs. Computed-column formulas complete column references, worksheet functions and variables, and parameter lines offer the query's undeclared parameters and every type. Accepting a setting opens its values straight away, so a whole directive can be written by picking from lists.

## Pivot and chart results of any size

Results big enough to be kept on disk no longer lock the Pivot and Chart tabs. Both now read every row of the result in the background each time you change the layout, showing "Pivoting…" or "Charting…" with a percentage meanwhile, and memory use stays flat however many rows there are. Charts of smaller results also improve: they now use every row instead of stopping at the first 10,000, and histograms count every value. Line, area and scatter charts of more rows than they can draw keep the overall shape, spikes and dips included, and say how many rows the points summarize. Drill-through works on these results too: double-clicking a pivot cell, or clicking a bar, slice or histogram bin, collects exactly the rows behind it in the background ("Finding matching rows…") and shows them on the Grid tab under the usual banner, whose Clear brings back every row, while the Pivot and Chart tabs keep covering the whole result. Clicking a point on a line or scatter chart jumps to its row. Export, copy and the other grid tools work on the filtered rows, and memory stays flat because the matching rows are kept on disk and removed when you clear the filter or run the next query. The tabs stay locked while a large result has unsaved edits.

## "Fix this" link reachable when several columns are flagged

When a query had more than one ungrouped column, the problem tooltip for the first column covered the next ones. Moving the mouse down to its "Fix this" link passed over their underlines, and the tooltip kept switching to the next problem, so the link could never be clicked. The tooltip now stays put while the mouse is over it.
## Translation review fixes in eight languages

A meaning-for-meaning review of the German, French, Japanese, Korean, Brazilian Portuguese, Russian and both Chinese catalogs against the English fixed thousands of strings: wrong database terms (row and column mix-ups, "refresh", "restriction" versus "constraint"), inconsistent wording between sibling menu items, mixed formality, and translated code, keywords and version numbers that should have stayed in English. Japanese and Chinese saw the most changes.
