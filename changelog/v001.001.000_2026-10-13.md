# 2026-10-13

## Browser build: the rename pencil and other symbols no longer render as boxes

In the browser version of SQLly the pencil for renaming a result set showed as a box, because the fonts embedded in the browser build lacked that glyph (the desktop app takes it from the system fonts). The embedded fonts now carry the pencil, the dialog pop-out arrow, the search magnifier, the pane-divider triangles, the unselected radio circle and the status-bar separator, and a test fails the build whenever the app starts drawing a symbol the browser fonts do not have.

## Running a query reopens a collapsed results pane

If you had collapsed the results pane and then ran a query, the results stayed hidden and you had to open the pane yourself to see them. Running a query (including multi-target runs, AI runs and confirmed mutations) now opens the results pane automatically. Auto-refresh ticks and notebook cells leave it as you set it.
