# 2026-10-19

## Remote sessions no longer hang when the first handshake message arrives with the relay's sign-in reply

A bridge or app connecting through the relay could sometimes stall until it timed out. If the other side's first handshake message arrived in the same network read as the relay's sign-in acknowledgement, it was thrown away along with the sign-in buffer, and the handshake waited for a message it had already received. The connection now keeps those buffered bytes when it moves from signing in to the encrypted session.
