# 2026-08-23

## Mainline editor splits, find/replace, and IntelliSense cache land on the new workbench

The redesigned workbench now includes the editor features that shipped on main while we were restyling: split the query area vertically or horizontally, find and replace in the current script, and inspect or clear the IntelliSense cache from Settings. Split panes use the same hairline dividers and per-pane editor/results stacks as the rest of the chrome, and the find bar sits on the editor as a quiet overlay.
