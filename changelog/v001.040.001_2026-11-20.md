# 2026-11-20

## Bundled zlib security fix restored

Version 1.40.0's build put back an older copy of the zlib compression library with a heap buffer overflow in its file-writing code (RUSTSEC-2026-0544). 1.40.1 ships the fixed zlib again.

## Notebook PDF exports read fonts with a maintained library

PDF exports from notebooks now read their built-in fonts with a maintained font library instead of one that is no longer updated. Reports look the same.

## `sqlly-cli notebook cat` prints the same output on every build

The `cat` output used for Git diffs listed settings in a different order depending on how the command-line tool was built, which could make `git diff` show changes that weren't there. Settings are now always listed in alphabetical order.
