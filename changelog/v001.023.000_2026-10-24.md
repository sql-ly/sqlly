# 2026-10-24

## macOS notifications show the SQLLY icon

System notifications for long queries, failed queries and finished exports
were posted through `osascript`, so macOS showed them as coming from Script
Editor, with its icon. They now go through the native notification center
and show SQLLY's name and icon. The first one asks for notification
permission. A build run outside an app bundle (`cargo run`) still uses the
old route.

## Service messages are ready for English and Spanish

Execution-plan findings, administration and security errors, Redis live-capture status, browser sign-in pages, script templates, table-structure warnings, and related service messages now carry stable translation descriptions and named values for the interface to localize at display time. English and Spanish catalogs cover this service copy while SQL, logs, protocol data, and original server diagnostics remain unchanged.
