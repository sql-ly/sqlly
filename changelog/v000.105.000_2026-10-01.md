# 2026-10-01

## Explorer filter no longer leaves folders expanded after it is cleared

The server explorer now remembers which folders were open when you start
typing a filter and puts them back when the filter is cleared. Before, the
filter revealed matches under collapsed folders, and clicking any of those
rows flipped the folder's stored state, so clearing the filter left every
folder the search had touched hanging open. The one exception is deliberate:
an object you picked during the search stays revealed and is scrolled into
view, since that is what the search was for.

## Stored procedure, view, and trigger definitions longer than 8 KB are no longer truncated

Loading an object's DDL went through the grid's streaming path, which cuts
every text cell to an 8 KB preview, so long procedure sources came back
silently cut off mid-statement. Definition and metadata fetches now use the
full-value path and arrive whole.
