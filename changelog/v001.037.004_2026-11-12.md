# 2026-11-12

## Release builds no longer fail on translated brace examples

The v1.37.3 release build failed its tests on macOS, Windows and Linux. A check that every translation keeps the same `{name}` placeholders as the English text mistook the escaped literal braces in one message (`{{{{ or }}}}`) for a placeholder, so the Spanish wording "o" looked like a different placeholder from the English "or". The check now treats doubled braces as literal braces, the same way the app formats messages. The translations themselves were already correct.

## Traditional Chinese no longer shows the wrong help text under Reasoning

In Settings → AI → Cloud, the help text under the Reasoning dropdown for OpenAI-compatible profiles showed the Mac App Store message about local agent tools instead of its own explanation that `reasoning_effort` is sent only while the "Send reasoning_effort" checkbox is on. The Traditional Chinese text now matches what the screen actually says.
