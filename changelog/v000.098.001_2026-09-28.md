# 2026-09-28

## A redesigned Formatting Directives reference

Help ▸ Formatting Directives now opens a two-pane reference instead of one long plain list. Each directive family is listed on the left by a plain name, such as Column format, Pivot table or Canvas layout, with its `-- sqlly` keyword under it. Pick one, or move through the list with the Up and Down keys, to see its card on the right: what it does, its syntax in a code block, a table of its parameters, and ready-to-paste examples. Every example has a visible Copy button, and you can also press Enter on a focused example to copy it. The filter at the top narrows the list as you type.

## Problems with a `-- sqlly` directive are no longer hidden

When a `-- sqlly` comment has a problem, such as a misspelled `column=`, the warning popup now shows instead of the directive info popup, which used to paint right over it. The warning popup also ends with a "See SQLLY formatting directives →" link that opens the reference.

## Editor popups close when the pointer leaves the editor

Hover cards, warning popups, the directive info popup, fold previews and the gutter run button now go away when the mouse leaves the query editor. Before, they stayed on screen until the pointer came back.
