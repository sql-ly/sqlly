# 2026-11-09

## Clearing a temp table no longer asks for confirmation

`DELETE FROM #staging` and `DELETE FROM @rows` were being flagged as unconstrained deletes again once the SQL reader started recognising `#temp` tables and `@table` variables as real table names. Session-scoped tables hold no real data, so deleting from them without a WHERE is no longer flagged, whichever way the statement is read.
