# 2026-08-05

## SQLly Bridge downloads

The on-prem SQLly Bridge — the connector you run next to your databases so you can reach them through a relay — now ships with each release, with a build for each platform: Windows (x64), Linux (x64 and ARM), and macOS (Apple Silicon). The desktop app downloads are unchanged.

## Version 0.27.0

The application version moved from 0.26.0 to 0.27.0.
