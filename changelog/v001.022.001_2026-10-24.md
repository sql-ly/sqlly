# 2026-10-24

## Crypto advisory RUSTSEC-2026-0387 reviewed

A security advisory published today covers an old version of a big-number crypto library (RUSTSEC-2026-0387). That version reaches SQLly only through a token library that has no release yet using the fixed version, and SQLly uses it only to verify signatures, which involves no secret keys, so a timing leak there has nothing to expose. The advisory is now recorded as reviewed, with a date to check again.
