# 2026-10-23

## Dependency audit clean again; routine library updates

The dependency audit was failing on a timing-leak advisory in `ctutils`, a small constant-time helper used by the SSH key and encryption libraries. It is updated to the fixed release. The audit config also listed eleven git sources the app no longer uses, which it now drops; any git dependency that shows up again fails the audit until someone allows it on purpose.

Compatible updates to the AWS SDK, Redis driver, MCP server library, `uuid`, `ureq`, ICU and others were taken as well. DuckDB is held at 1.5.6: 2.0 is available, but the Windows build ships DuckDB's prebuilt library pinned by checksum, so the move needs its own change. The version requirement now blocks a routine update from picking up 2.0 by accident. Held back on purpose: gpui-component 0.8 (needs the gpui platform layer re-vendored), keyring 4 (a rewrite, deferred earlier), and parking_lot 0.13 (released two days ago and changes lock fairness, while the rest of the dependency graph still uses 0.12).
