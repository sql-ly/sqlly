# Security

Please report vulnerabilities privately to <support@sqlly.app> rather than in a public issue. Include steps to reproduce and the SQLly version.

In scope:

- the desktop app and command-line tools in this repository;
- the app↔bridge protocol (`sqlly-wire`, `sqlly-remote`);
- the SQLly bridge, relay and sqlly.app services, which aren't in this repository.

We'll confirm receipt within a few days and keep you updated until a fix ships. Please give us a reasonable time to fix the issue before you disclose it.
