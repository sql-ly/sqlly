# Feature SVG Asset Catalog

Transparent, scalable SVG graphics for the app's feature groups.

All assets use a `256x256` viewBox, no background fill, and accessible `<title>` / `<desc>` metadata. They are intentionally original and do not copy SSMS icons or Microsoft proprietary artwork.

| Asset | Intended feature area |
| --- | --- |
| `app-shell.svg` | Native macOS workspace shell, panes, tabs, toolbar |
| `connection-profiles.svg` | Connection profiles, authentication, TLS, Keychain |
| `query-workspace.svg` | Query editor, execution, selected-text execution |
| `object-explorer.svg` | Object Explorer tree, metadata browsing, refresh |
| `results-grid.svg` | Result sets, virtualized grid, copy/export |
| `scripting-engine.svg` | Script create/alter/drop, script targets, dependencies |
| `intellisense-templates.svg` | IntelliSense, snippets, Template Explorer, history |
| `execution-plans.svg` | Actual/estimated plans, warnings, operator details |
| `table-editing.svg` | Edit top rows, table data editing, properties |
| `backup-restore.svg` | Backup, restore, recovery workflows |
| `activity-monitor.svg` | Sessions, waits, blocking, expensive queries |
| `sql-agent.svg` | SQL Server Agent jobs, schedules, history |
| `security-management.svg` | Logins, users, roles, permissions |
| `azure-cloud.svg` | Azure SQL, Entra ID, cloud capability adaptation |
| `import-export.svg` | CSV import/export and data movement |
| `schema-compare.svg` | Schema compare and script diff output |
| `query-store-events.svg` | Query Store, Extended Events, diagnostics streams |
| `designers-long-tail.svg` | Designers, diagrams, BI/admin long-tail parity |
